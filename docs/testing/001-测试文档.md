## 1. 测试概述

测试按照 `docs/测试规范/` 约定分为两大类：**单元测试** 和 **集成测试**。

| 类型 | 位置 | 数量 | 说明 |
|------|------|------|------|
| 单元测试 | `tests/unit/` | 7 | 不依赖外部环境，测试纯逻辑 |
| 集成测试 | `tests/integration/` | 5 | 启动完整 Server，测试 JSON-RPC 全链路 |
| **合计** | | **12** | |

## 2. 测试文件清单

### 2.1 测试辅助

| 文件 | 职责 |

| `tests/testdata/config.test.toml` | 测试专用 TOML 配置（独立端口 18080，独立 DB） |

## 4. 运行方式

```bash
# 全量测试
go test ./tests/... -v -count=1

# 仅单元测试
go test ./tests/unit/... -v -count=1

# 仅集成测试
go test ./tests/integration/... -v -count=1

# 单个用例
go test ./tests/unit/operation/mapping/ -v -count=1 -run TestMappingValidate
```

## 5. 测试配置

集成测试使用独立配置文件 `tests/testdata/config.test.toml`：

- 监听独立端口 `:18080`，不与生产冲突
- 独立 SQLite 数据库 `/tmp/kgbrain-test.db`
- 日志级别 `error`，减少测试输出噪音

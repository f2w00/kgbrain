## 1. 概述

内容映射服务用于将源值映射到目标值（如 "唐朝" → "唐"），按 topic 组织映射表。
与字段映射（mapping.field）不同，内容映射处理的是**值级别**的映射，而非字段级别。

### 使用场景

```
用户设定 dynasty 的目标值: ["唐", "宋", "明", "清"]
请求映射: {topic: "dynasty", values: ["唐朝", "宋朝", "元朝"]}
返回: {topic: "dynasty", mapping: {"唐朝": "唐", "宋朝": "宋", "元朝": "元"}}
```

### 工作流程

```
mapping.content {topic, values}
    → 查 SQLite: 已有映射直接返回
    → 未命中: 调 LLM 映射
    → 新映射存入 SQLite
    → 返回完整映射表（包含本次新增的映射）
```

## 2. API

### mapping.content

查询并自动补全内容映射，返回完整映射表。

```json
{
  "method": "mapping.content",
  "params": {
    "profile_id": "user_abc",
    "topic": "dynasty",
    "values": ["唐朝", "宋朝", "元朝"]
  }
}
```

### 响应

```json
{
  "topic": "dynasty",
  "mapping": {
    "唐朝": "唐",
    "宋朝": "宋",
    "元朝": "元"
  }
}
```

### mapping.content.set

设置/更新某个 topic 的完整映射表。

```json
{
  "method": "mapping.content.set",
  "params": {
    "profile_id": "user_abc",
    "topic": "dynasty",
    "mapping": {
      "唐朝": "唐",
      "宋朝": "宋",
      "明朝": "明"
    }
  }
}
```

### 响应

```json
{
  "success": true
}
```

## 3. 架构

```
mapping.content {profile_id, topic, values}
    │
    ├── 获取 profile 的 LLM 配置
    │
    ├── 查 SQLite: content_mapping 表
    │   ├── 命中: 直接使用已有映射
    │   └── 未命中:
    │         LLM → 新映射 → 存入 SQLite
    │
    └── 返回完整映射表（包含本次新增的映射）

mapping.content.set {profile_id, topic, mapping}
    │
    └── 直接覆盖写入 SQLite
```

## 4. 存储设计

### content_mapping 表

```sql
CREATE TABLE content_mapping (
    topic      TEXT NOT NULL,
    profile_id TEXT NOT NULL,
    mapping    TEXT NOT NULL,    -- JSON: {"唐朝": "唐"}
    updated_at TEXT NOT NULL,
    PRIMARY KEY (topic, profile_id)
)
```

- topic + profile_id 联合主键
- mapping 字段存储 JSON 格式的完整映射表
- 每次写入覆盖整个 topic 的映射表

## 5. 调用端缓存示意 (Python)

```python
# 调用端本地缓存
local_cache = {}  # {topic: {source: target}}

def apply_content_mapping(topic, values, server_mapping):
    """应用服务端返回的映射表，更新本地缓存"""
    local_cache[topic] = server_mapping
    return {v: server_mapping.get(v, v) for v in values}

# 使用
result = apply_content_mapping("dynasty", ["唐朝", "宋朝"], server_response["mapping"])
```
